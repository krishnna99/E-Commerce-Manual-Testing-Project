E-Commerce Web Application – Manual Testing Project

1. Project Overview
This project focuses on manual functional testing of the nopCommerce Demo Store, an e-commerce web application.

Application:nopCommerce Demo Store  
URL: https://demo.nopcommerce.com/  
Testing Type:Manual Testing  
Domain: E-Commerce

2. Testing Objectives
Verify application functionality.
Identify defects and unexpected behavior.
Validate positive and negative scenarios.
Check input fields and form validations.
Verify shopping cart and checkout workflows.

3. Modules Tested

1. Home Page
2. Product Search
3. Product Details
4. Registration
5. Login
6. Shopping Cart
7. Checkout

8. Execution Status
Testing was performed across the seven listed modules. Actual results and execution statuses were documented in the test cases.
